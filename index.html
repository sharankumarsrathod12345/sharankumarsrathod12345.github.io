BEFORE WE WORK TOGETHER

A few practical details.

What do you need to start?

A short description of the decision you need to make, a sample of your data, the reports you use today, and your preferred timeline. Share confidential data only through an agreed private channel.

What determines the project scope?

The number of sources, data quality, complexity of the metrics, dashboard interactions, and refresh requirements. We agree deliverables and review steps before work begins.

Will I receive editable files?

Editable dashboard files, workbooks or SQL scripts can be included in the agreed deliverables, along with the definitions and instructions needed to use them.

Are these dashboards connected to live client data?

No. The featured work consists of portfolio demonstrations. The Tableau dashboard is interactive; Excel workbooks can be downloaded from their repositories. The calculator uses a separate illustrative scenario.
