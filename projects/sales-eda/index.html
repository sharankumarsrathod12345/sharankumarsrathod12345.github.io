SQL SERVER / PORTFOLIO CASE STUDY

Sales EDA with SQL

How much was sold, who purchased, and which products had no recorded sales? Explore the warehouse and check that the joins preserve the totals.

Explore the repository ↗

Start with the warehouse

Explore the sales fact table and the customer and product dimensions. Inspect date coverage and distinct categories before deciding which comparisons the data supports.

Define an order before counting it

One order can contain several sales rows. The executive summary counts distinct order numbers for order volume and sums quantities for units sold. It separates mean line unit price from realized sales per unit.

Find patterns worth investigating

Compare sales by country and product category, rank products by key, and identify catalog products with no recorded sales. The monthly analysis compares sales, distinct orders, units and average order value. A missing prior month is left blank.

Check the joins

Validation queries check dimension keys, unmatched sales rows and totals before and after joining. The repository includes fixture tests for these rules. Native SQL Server execution and dataset-specific results are listed as pending for this EDA project.
